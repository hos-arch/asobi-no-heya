# あそびの へや

療育のあそびアプリを、上から順に並べた入口のページです。
参考書籍の考え方をもとにした試作です。治療の効果をうたうものではありません。
名前・記録・写真・声は保存しません。

## 公開
- GitHub に置いて、Cloudflare で公開します（他のアプリと同じ）。
- `public/index.html` と `wrangler.jsonc`（assets は `./public`）。

## アプリを一覧に足す（自動）
ページを開くたびに、GitHub の `hos-arch` の公開リポジトリから、
トピック **`ryoiku-app`** がついたものを探して、一覧に足します。

新しいアプリを作ったら、そのリポジトリで次の3つをします。

1. リポジトリのトップ右の「About」の歯車 → **Topics** に `ryoiku-app` を入れる。
2. 同じ「About」の **Website** に、Cloudflare の公開アドレスを入れる。
3. リポジトリのいちばん上に **`app.json`** を置く（`app.json.example` を写して直す）。

これで、まとめページを開き直すと、カードが足されます。まとめページの作り直しはいりません。

### app.json の中身
| 項目 | 内容 |
|---|---|
| id | リポジトリ名と同じにする |
| title | ひらがなの題名 |
| desc | 一行の短い説明（支援者向け） |
| url | 公開アドレス。空なら About の Website を使う |
| order | 並び順だけに使う数（画面には出ない）。例 `[7, 2]` |
| icon | 絵の名前（oto, te, hako, sasu, hame, kaku, kiru, oru, kumitate, mihon, kao）。ないときは星の絵 |
| thumb | 画像を使うとき、リポジトリの中の場所（例 `thumb.png`）。空なら icon の絵 |
| group | `main`（上の並び）／ `other`（下の「ほかの あそび」） |
| hidden | `true` で一覧から隠す（作りかけのとき） |

### 並び順（order）
療育の段階の若い順に、上から並べます。
| 並び | アプリ | order |
|---|---|---|
| 1 | おとを みる | [1, 2] |
| 2 | て あそび | [5, 1] |
| 3 | はこ あそび | [5, 2] |
| 4 | さす あそび | [6, 1, 1] |
| 5 | はめ あそび | [6, 1, 2] |
| 6 | かく あそび | [6, 2] |
| 7 | きる あそび | [6, 3, 1] |
| 8 | おる あそび | [6, 3, 2] |
| 9 | くみたて あそび | [7, 1, 1] |
| 10 | みほん くみたて あそび | [7, 1, 2] |
| 11 | かお からだ あそび | [7, 2] |

## GitHub が読めないとき
- リポジトリが非公開、または GitHub の読み取りの回数の上限（1時間に60回／端末ごと）に達したときは、
  `index.html` の中の予備の一覧（`LOCAL`）だけを出します。
- 予備の一覧の `url` が空のアプリは、「じゅんび中」として押せない形で出ます。
